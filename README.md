# مساعد التسويق الذكي ✦

تطبيق ويب عربي (RTL) يولّد محتوى تسويقي باللهجة السعودية للأنشطة التجارية:
منشورات انستجرام، أفكار ريلز، خطط محتوى أسبوعية، ردود على العملاء، وهاشتاقات.

## المميزات
- واجهة عربية كاملة، بهوية كحلي/ذهبي، تعمل من الجوال.
- يعمل **مجانًا 100%**: كل مستخدم يلصق مفتاحه المجاني من صفحة الإعدادات داخل التطبيق (Google Gemini أو Groq).
- لا يوجد خادم ولا اشتراكات: التطبيق صفحة ثابتة واحدة (`index.html`)، والمفتاح ينحفظ في متصفح المستخدم فقط.
- بدون أسعار في المحتوى المولّد (قاعدة ثابتة في التطبيق)، والدعوة دائمًا للتواصل عبر واتساب.

## التشغيل (GitHub Pages)
1. ارفع `index.html` إلى هذا المستودع.
2. من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → main → Save**.
3. بعد دقيقة يفتح الموقع على: `https://mohsenalariqy.github.io/Ai/`

## طريقة الاستخدام للعميل
1. افتح الرابط من الجوال.
2. اضغط ⚙ الإعدادات → اختر Google Gemini → اتبع الخطوات لإنشاء مفتاح مجاني والصقه → حفظ.
3. اكتب طلبك أو اختر قالبًا جاهزًا (منشور / ريلز / خطة محتوى) واستلم المحتوى جاهزًا للنسخ.

## حدود النسخة المجانية
- مفتاح Gemini المجاني له حد يومي/بالدقيقة يكفي للاستخدام الفردي الطبيعي؛ عند تجاوزه يظهر تنبيه ويُعاد المحاولة بعد دقيقة.
- المحتوى مولّد بالذكاء الاصطناعي ويحتاج مراجعة قبل النشر.
