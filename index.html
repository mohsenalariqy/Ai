الإعدادات

التطبيق يعمل بمفتاح مجاني تحصل عليه بنفسك خلال دقيقتين. المفتاح ينحفظ في جهازك فقط وما يُرسل لأي جهة غير مزود الخدمة. 📖 دليل البداية خطوة بخطوة

طريقة الحصول على مفتاح Gemini المجاني:
  1. افتح aistudio.google.com/app/apikey
  2. سجل دخولك بحساب قوقل
  3. اضغط Create API key
  4. انسخ المفتاح والصقه تحت
طريقة الحصول على مفتاح Groq المجاني:
  1. افتح console.groq.com/keys
  2. سجل حساب مجاني
  3. اضغط Create API Key
  4. انسخ المفتاح والصقه تحت
